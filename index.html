S1: Foundation and Reset

This section demonstrates the foundational CSS rules used throughout the fitness design system.

My CSS reset used box-sizing: border-box to make the element widths easier to manage. It also strips default body margins and padding to create a consistent starting point.

S2: Token Inventory

This section shows the reusable design values for our fitness website.

Color Tokens

  • Primary: #2563eb - Main buttons and header
  • Secondary: #16a34a - Hover and focus states
  • Background: #f8fafc - Main page background
  • Surface: #ffffff - Cards and content sections
  • Text: #1e293b - Main readable text
  • Border: #cbd5e1 - Component borders

Other Design Tokens

  • Spacing: 8px, 16px, 24px, 40px -Gaps and padding
  • Content Width: 1100px - Limits line length
  • Border Radius: 8px - Rounded corners
  • Shadow: 0 4px 12px rgba(0, 0, 0, 0.1) - Card elevation
  • Font: Arial, Helvetica, sans-serif - typography with fallbacks
  • Base Font Size: 16px - Standard body text
