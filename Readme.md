# Fitness Design System
## Project Overview

This is a fitness-themed design system built using HTML and CSS. Showing reusable design tokens, typography, button, content components, form controls, and alt color themes.

## Design Decisions
 -Colors: Blue is primary action, green is interactive actions
 -spacing: reusable spacing tokens create consistency
 -typography: Arial,Helvetica and sans-serif are text options
 -components: buttons, cards, and form controls utilize design tokens
 -themes: light and dark themes show how color tokens can be changed without a complete rebuild.
